Features

🔎

Smart matching

Phrase matches when a post contains all its words in any grammatical form — Russian lemmatization via pymorphy3. «ищу квартиру» catches «ищем квартиру».

🚫

Negative keywords

Landlord ads, wrong countries, excursion spam — one stop-word hides them everywhere, retroactively. Dictionaries are edited straight in the bot.

✍️

AI reply drafts

One tap generates a friendly reply pitching your apartments, hooked to the post's dates and city. Copy-to-clipboard button included.

⭐

Favorites & CSV

Star the best leads, export everything to CSV with match / filter annotations for each post.

💬

Comment watch

Any new comment under your own Facebook posts triggers an instant alert — no filters applied.

🔐

Stars paywall

Access via date-derived daily / monthly passwords. Password images are generated on the fly and sold for Telegram Stars.

How it works

ScrapeApify actor pulls fresh posts from your Facebook groups once a day. Everything lands in SQLite.
MatchLemma-based phrase matching + negative keywords. Filters are reactive — edit words, results change instantly.
AlertTelegram bot pings your DM and team group with each lead, grouped by source.
ReplyLLM drafts the answer, you tap “copy” and paste it under the post. Done.

Quick start

# clone & install
git clone https://github.com/neo37/fb-group-monitor && cd fb-group-monitor
python3 -m venv .venv && .venv/bin/pip install aiogram pymorphy3 requests pillow
cp .env.example .env # add your tokens
.venv/bin/python bot.py # the dashboard bot
.venv/bin/python worker.py # daily scrape pass (systemd timer / cron)
